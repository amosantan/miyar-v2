# Documentation Archive

This directory contains non-authoritative historical evidence. Current requirements and repository facts live in the canonical documents at `docs/` root.

## Collections

| Path                   | Contents                                                                      |
| ---------------------- | ----------------------------------------------------------------------------- |
| `historical-reports/`  | Build reports, phase reports, legacy progress records, and version history    |
| `plans/`               | Superseded strategic plans, roadmaps, and reviews                             |
| `specs/`               | Completed or superseded specifications, task lists, and phase trackers        |
| `antigravity-history/` | Imported agent traces, browser evidence, plans, reports, and supporting media |

Historical paths, commands, counts, providers, and completion claims must be reverified against the live checkout before use. See `historical-reports/README.md` for retention and evidence rules.
