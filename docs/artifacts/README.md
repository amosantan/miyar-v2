# Project Artifacts

This directory groups non-source project deliverables separately from canonical Markdown documentation.

| Path         | Intended contents                                         |
| ------------ | --------------------------------------------------------- |
| `financial/` | Financial models and revenue workbooks                    |
| `planning/`  | Delivery and reporting plans                              |
| `prompts/`   | Reviewable prompt documents used for bounded project work |
| `qa/`        | QA briefs, consistency reviews, and presentation briefs   |
| `reports/`   | Sanitized report samples used as project evidence         |

Before committing an artifact, verify that it is intentional, stable, reasonably sized, free of secrets and customer data, and not a temporary Office lock file. Prefer source formats and Git LFS for frequently changing large binaries.
