**Key findings**

- Pointing an Obsidian vault at this repo root is safe **only with enforced scoping**. Live server:
  654 indexed notes — 193 canonical, **438 (67%) stale `.claude/worktrees/` duplicates**, 0 from
  `node_modules`. Hence mandatory `excludePaths`.
- **Corrected my own claim mid-build.** Before the server was live I asserted from disk counts that ~93%
  of the index was `node_modules` + worktrees. Measuring the running server disproved the `node_modules`
  half — mcpvault skips it by default. The worktree half was not only right but understated: an unscoped
  probe returned the *same* document at ranks 1, 2 and 3 from three checkouts. Corrected across six
  files and recorded rather than overwritten. First real exercise of the correction discipline.
- The repo already declared "repository state is the durable memory". The second memory was therefore
  scoped to only what the repo did *not* own — terminology, people, domain, research, narrative.
  Verified zero verbatim overlap with canonical files.
- The Trading vault described MIYAR as an academic postgraduate business plan. Corrected in three files
  there.

**Verification:** 6 hook tests passed (empty-session no-op, commit record, PreCompact de-duplication,
staleness warning, non-git safety, exit 0 throughout). No TypeScript touched.

**Next:** restart Claude so `obsidian-miyar` loads, then run the negative/positive scoping controls

## Session — Live verification and main-checkout recovery

**Live controls passed.** Restarted; `obsidian-miyar` connected. Negative control returned the same
document at ranks 1–3 from three checkouts; scoped control returned 6/6 canonical hits. Scoping works.

**Found local `main` was 65 commits behind `origin/main`**, with 8 uncommitted files on that stale base.
Assessment (3-way merge simulation, read-only, everything backed up first):

- 3 files — `.gitignore`, `AGENTS.md`, `CLAUDE.md` — carried durable conventions upstream never received
  (PlanetScale credential convention; plan-orchestrator routing). Merged clean; landed on
  `claude/land-pending-conventions` off current `origin/main`.
- 5 state files described 2026-07-17 (UX-01 active, next step BR-03, 973 tests). Upstream had since
  closed UX-01/BR-03/BR-04/BR-05 and moved to BR-06 with 1,264 tests. **Merging them would have rolled
  the execution ledger back four steps.** Discarded with authorization after byte-identical backup.
- `.agent/skills/miyar-plan-orchestrator/` was untracked *and* absent upstream, while the AGENTS.md and
  CLAUDE.md edits referenced it by path — landing those two files alone would have created a dangling
  reference. Committed together instead.

Local `main` fast-forwarded to `c7054c0`, now 0/0 with origin.

**Reusable lesson (candidate for `.agent/state/LESSONS.md`):** uncommitted *state* files are not
harmless work-in-progress. Ordinary source edits go stale; state files go **actively wrong**, because
they assert a current position that a moving repository has already invalidated. The longer they sit,
the more confidently they lie. Worth a staleness check on any checkout that has drifted.

pushed and no PR was opened. Both are committed and ready.
