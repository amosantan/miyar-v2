## Session — Build the MIYAR second memory

**Goal:** Give MIYAR a durable second memory that survives sessions and is shared with Codex.

**What was built**

- `memory/` — 13 notes across 7 folders (glossary, people, projects, context, domain, research,
  decisions, journal), with a hot-cache index at `memory/README.md` and a closed tag list in
  `memory/TAG_TAXONOMY.md`.
- `.claude/hooks/session-start.sh` + `session-end.sh`, wired via `.claude/settings.json` on
  `SessionStart`, `SessionEnd`, and `PreCompact`.
- `.claude/skills/miyar-memory/SKILL.md` — the interpretive session-close cascade.
- Contract in `AGENTS.md` (so Codex is bound too), Claude mechanics in `CLAUDE.md`, shared procedure in
  `docs/runbooks/memory-sync.md`, and the Memory Model table in `docs/runbooks/roadmap-execution.md`
  extended so there is one memory model rather than two.

**Key findings**

- Pointing an Obsidian vault at this repo root is safe **only with enforced scoping**. Live server:
  654 indexed notes — 193 canonical, **438 (67%) stale `.claude/worktrees/` duplicates**, 0 from
  `node_modules`. Hence mandatory `excludePaths`.
- **Corrected my own claim mid-build.** Before the server was live I asserted from disk counts that ~93%
  of the index was `node_modules` + worktrees. Measuring the running server disproved the `node_modules`
  half — mcpvault skips it by default. The worktree half was not only right but understated: an unscoped
  probe returned the *same* document at ranks 1, 2 and 3 from three checkouts. Corrected across six
  files and recorded rather than overwritten. First real exercise of the correction discipline.
- The repo already declared "repository state is the durable memory". The second memory was therefore
  scoped to only what the repo did *not* own — terminology, people, domain, research, narrative.
  Verified zero verbatim overlap with canonical files.
- The Trading vault described MIYAR as an academic postgraduate business plan. Corrected in three files
  there.

**Verification:** 6 hook tests passed (empty-session no-op, commit record, PreCompact de-duplication,
staleness warning, non-git safety, exit 0 throughout). No TypeScript touched.

**Next:** restart Claude so `obsidian-miyar` loads, then run the negative/positive scoping controls
against the live server. `memory/` only becomes visible to the lens once this branch merges to main.
